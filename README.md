## projects
* [LikeVault](https://github.com/netCrunch/LikeVault) - a local-first Chrome and Firefox extension for turning TikTok likes and favourites into a searchable archive, with filtering, sorting, and JSON/CSV export.
* [FollowTrace](https://github.com/netCrunch/FollowTrace) - a privacy-first Firefox extension for tracking Instagram followers and following over time, with local snapshots and optional bulk unfollow actions through your existing browser session.
